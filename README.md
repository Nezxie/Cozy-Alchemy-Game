# Alchemy game
This is just a fun little game where you try to create potions by mixing different ingredients.
There is no particular reason why I made it, I just wanted to have some fun.

### Want to run it? 
Download the files, 
```npm install```
to install then 
```run vite```
and open the localhost link provided in the console.
Or just visit [i'll add _github link_ here later] and play.
